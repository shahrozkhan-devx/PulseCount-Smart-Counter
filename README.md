# 🔢 Counter App

A **simple and stylish JavaScript Counter App** built with **HTML, CSS, and Vanilla JavaScript**.  
This project allows users to increment, decrement, reset, and change values with smooth UI interactions.

🌐 **Live Demo:**  
👉 https://danish-devx.github.io/Counter-App/

---

## ✨ Features

- ➕ Increment counter  
- ➖ Decrement counter  
- 🔄 Reset counter  
- 🚫 Prevents negative values  
- 🎨 Clean & modern blue UI theme  
- ⚡ Real-time DOM updates  
- 🧠 Beginner-friendly logic  

---

## 🛠️ Technologies Used

- **HTML5** – Structure  
- **CSS3** – Styling & layout  
- **JavaScript (ES6)** – Logic & DOM manipulation  

---

## 📂 Project Structure

Counter-App/ │ ├── index.html ├── style.css └── app.js

---

## 🚀 How It Works

- Buttons trigger JavaScript functions  
- Counter value updates dynamically using DOM methods  
- Logic ensures the counter never goes below zero  
- UI updates instantly for a smooth user experience
